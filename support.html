How ScriptFloww works.

ScriptFloww is a forward-only writing app. Type into the page; if you pause for more than seven seconds, the page resets and the session is captured for export.

Where did my text go?

Sessions clear on purpose — that's the whole point. If you want to keep one, tap Export in the session-complete sheet before starting a new one. Export routes to the iOS share sheet on device, or the browser print dialog on web (save as PDF from there).

Why can't I use backspace?

By design. The app is built for writing past mistakes instead of editing them. Copy and paste are also disabled.

Does it work offline?

Yes. The only network request is a stylesheet for the Manrope font; the app still functions if it fails to load — it'll just use your system's default sans-serif.

Can I make the timer longer?

Not yet. Two seconds of grace + a five-second visible countdown is the whole spec.
